نسخه کامل سایت کتابخانه

ویژگی‌ها:
- رابط کلاسیک کتابخانه با رنگ‌های کرم، قهوه‌ای، خاکستری و مشکی
- بدون ایموجی
- جستجو در صفحه جداگانه
- دسته‌های عاشقانه و فانتزی حذف شده‌اند
- پنل مدیریت کتاب‌ها
- آمار بازدید امروز، کل، صفحه اصلی، صفحات کتاب و نمودار ۷ روزه
- تبلیغات فقط از نوع ثابت
- تبلیغ فقط وقتی فعال و در بازه زمانی باشد نمایش داده می‌شود
- امکان ویرایش و حذف تبلیغ از پنل مدیریت

راه‌اندازی:
1. همه فایل‌های این پوشه را در ریشه مخزن GitHub خود آپلود و فایل‌های قبلی را جایگزین کنید.
2. در Supabase وارد SQL Editor شوید.
3. فایل ads.sql را باز کنید. عبارت YOUR_ADMIN_UUID را با UUID حساب مدیر جایگزین کنید و سپس Run را بزنید.
4. اگر جدول page_views را قبلاً ساخته‌اید، setup.sql را دوباره اجرا نکنید.
5. پس از Commit در GitHub سایت را باز کنید.

تبلیغات:
- از پنل مدیریت بخش مدیریت تبلیغات استفاده کنید.
- عنوان، متن، تصویر، لینک، زمان شروع، زمان پایان و وضعیت را تعیین کنید.
- برای حذف تبلیغ روی حذف بزنید.
- اگر هیچ تبلیغ فعال و معتبر زمانی وجود نداشته باشد، هیچ پنل تبلیغاتی در سایت نمایش داده نمی‌شود.
